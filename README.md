# Retail-Inventory-Demand-Forecasting
## Project Overview
This project analyzes retail inventory, sales, demand forecasts, and supplier performance to identify inventory risks and support better inventory planning.

## Business Objectives
- Analyze inventory levels and units sold.
- Compare actual sales with demand forecasts.
- Identify products and regions that may require stock attention.
- Evaluate supplier lead times and reliability.
- Build an interactive Power BI dashboard for business insights.

## Tools Used
- **Excel:** Data inspection, auditing, and cleaning.
- **MySQL:** Data cleaning, SQL queries, and business analysis.
- **Python:** Exploratory Data Analysis (EDA) using Pandas.
- **Power BI:** Interactive dashboard and visual reporting.

## Project Workflow
1. Data inspection and quality checks.
2. Data cleaning and standardization.
3. SQL-based analysis.
4. Python exploratory data analysis.
5. Power BI dashboard development.
6. Business insights and recommendations.

## Key Analysis Areas
- Inventory levels and demand coverage.
- Units sold and units ordered.
- Demand forecast comparisons.
- Low-stock priority analysis.
- Supplier lead time and reliability.
- Category, region, and product performance.

## Project Status
Developed as a personal data analytics portfolio project.

## Note
Dataset characteristics and findings should be interpreted according to the source and nature of the data used.
