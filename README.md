# Retail-Inventory-Demand-Forecasting
## Retail Inventory Analytics

### Project Overview
This is a personal Data Analyst portfolio project using a simulated retail inventory dataset. The project demonstrates how data analytics tools can be used to analyze inventory levels, sales patterns, demand forecasts, and supplier performance.

### Business Objectives
- Analyze inventory levels and sales performance.
- Compare units sold with demand forecasts.
- Identify products that may require stock attention.
- Analyze supplier lead times and reliability.
- Build a Power BI dashboard to communicate business insights.

### Tools Used
- **Excel:** Data inspection, auditing, and cleaning.
- **MySQL:** Data cleaning, SQL queries, and business analysis.
- **Python:** Exploratory Data Analysis using Pandas.
- **Power BI:** Interactive dashboards and data visualization.

### Project Workflow
1. Data inspection and quality checks.
2. Data cleaning and standardization.
3. SQL-based business analysis.
4. Python exploratory data analysis.
5. Power BI dashboard development.
6. Insights and recommendations.

### Dataset Disclaimer
The dataset used in this project is simulated and does not represent verified transactions from a real retail company. The project focuses on demonstrating data cleaning, analysis, visualization, and business problem-solving skills.

### Project Outcome
A portfolio project demonstrating an end-to-end data analytics workflow using Excel, MySQL, Python, and Power BI.
